## Description
Dungeons and Cards is a simple card game where you fight an opponent, using cards with spells from DnD (which are slightly changed for this game). In the game, you use energy to select one or more cards before playing your turning, "casting" the spells. The cards do either random amounts of damage or healing depending on the selected cards. The opponent is similar to you as they have a hidden energy system and same moves, but they randomly select a single move to do compared to you. The game ends whenever you or the opponent's hp becomes 0 or less. 

Within the src directory, it contains the main project file, but it also contains a few pngs and mp3 files. The png files are for the cards displayed on the screen. The card images were created in photoshop. The mp3 files are for the music that plays in the main menu, during the battle, losing, and winning. The mp3 files were downloaded from Pixabay and should be royalty-free.

Originally, I had planned to have multiple stages, but I didn't really have enough time to really balance the fights to support multiple stages and figure out how to make each fight feel different from one another; therefore, I decided to have a single battle. Similary, I also wanted to have more visuals that would clearly show what happened, but I ended up settling on having a game board that writes out instructions and actions.

While I'm pretty happy with the results of the project, there are a few things I would've liked to add or tweak if I had more time. In relation to game elements, I would've liked to visualize who was the opponent and really just have some movement of the cards. In relation to the code, I would've liked to not have a lot of if statements in the functions, but I am currently unsure if it's possible due to the amount of conditions it needs to check for the card game elements. 

During the development of the project, I have thought of more ideas for the game that I didn't have time to implement. I was considering having multiple usable decks that were based on DnD's ability scores and would have different playstyles from each other. Again, I would've like to have multiple stages, which also meant having your hp save between fights and maybe gain things like cards or buffs. 

For my personal thoughts on this, I am honestly pretty proud of it. Although it is a very simple game, this really was the first time coding a playable game. The coding was a little rough, but I enjoyed how it ended up despite the possible issues the code still has that could be made better. I might implement some of the features and ideas that I couldn't do in the future as I already have a base of a game to build up from.
